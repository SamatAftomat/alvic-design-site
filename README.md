# Alvic Design — сайт

Одностраничный сайт для компании **Alvic Design** (ремонт и отделка квартир, офисов, помещений, Петрозаводск).

- Данные: карточка [2ГИС](https://2gis.ru/petrozavodsk/firm/70000001082810924) — цены, отзывы, фото, контакты
- Статический сайт: HTML + CSS + JS, без сборки
- Стиль: «Сигнальный чертёж» (Unbounded + Manrope)

## Локальный запуск

Любым статическим сервером, например:

    python -m http.server 8000

и открыть http://localhost:8000

## Структура

    index.html   — вся страница
    css/style.css
    js/main.js
    img/         — фото работ из галереи 2ГИС
